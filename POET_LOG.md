# ЖУРНАЛ КОЭВОЛЮЦИИ СРЕДЫ И ФОРМЫ (append-only; POET-стиль, §9 MODEL.md)

Соты: факт = строка. Каждая строка данных несёт sha256 предыдущей СЫРОЙ строки
(колонка prev, первые 12 hex); для первой строки prev = sha256('POET')[:12].
Подмена любой строки ловится СЛЕДУЮЩЕЙ строкой (и коммитом git — внешний якорь):
проверка `python3 poet.py --verify`. Строки пишет автомат poet.py (ночной крон
poet.yml); в репозитории файл лежит с ТОЛЬКО шапкой, без строк данных.
Смоук-прогоны (`--smoke`) идут в POET_LOG_smoke.md и в эти соты не попадают.

Колонки: среда — геном среды-кандидата линии POET (p — катализ, ρ — приток еды,
T — тики, L — предел длины строк: параметры chem.py); |F| лучшей — размер формы,
продолжающей линию (лучшая живая из сеянцев; при смерти породы — из перезапуска
от свежего мира); живых сред — размер архива пар (среда, форма) линии POET;
контроль — живых_сред/|F| линии КОНТРОЛЯ (случайные среды без селектора
новизны, тот же бюджет); вердикт: ПРОДВИНУТА — среда жива И минимально-нова
(пара в архиве), ЖИВАЯ — жива, но не нова (мимо архива), ТИШИНА — контур не
поднялся даже от перезапуска; «·перезапуск» — порода умерла в этом поколении.
