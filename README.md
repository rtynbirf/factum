# ФАКТУМ (FACTUM) v1.0

> Сердце улья: автомат, который ДЕЛАЕТ факты. **Факт = байты** (Закон #2).

Не документация, а работающий механизм: **модель + код + тесты + cron-автомат + журнал генезиса**.
Ядро аккаунта `rtynbirf` после чистого листа. Родословная: EMERGENT_CORE v0.1 → v0.4 — см. [GENESIS.md](GENESIS.md).

## Закон, который это ядро открыло

**ФОРМА = РЕКОМБИНАЦИЯ НА ПОВТОРЯЮЩЕМСЯ СУБСТРАТЕ.**

| мир | рекомбинация | субстрат | строгая форма | источник |
|---|---|---|---|---|
| SKI | вырождена (K-проекции, S-дублирование) | есть | 0/20 | LINEAR_RESULTS.md |
| BCI (линейный) | честная (каждый аргумент ровно 1 раз) | нет (типы дрейфуют 112–149 из 150) | 0/20 | LINEAR_RESULTS.md |
| химия (лигирование/расщепление строк) | честная | есть | **19/20** (p=0.12, приток 0.1) | CHEM_RESULTS.md |

- Одного из двух недостаточно: без субстрата — дрейф и тишина; без честной рекомбинации — тривиальные проекции.
- Диагностика отказов ⋆: SKI — 36 истинных несхождений (S-циклы и раздувание), BCI — 0/400 (⋆ тотален, доля определённых применений 1.00).
- Гипотеза 5.2 v0.3 («форма возникает, когда ⋆ не вырождается в проекцию») ОПРОВЕРГНУТА в сильной форме.
- Гипотеза D (ИНВАРИАНТНОСТЬ ∧ ВАРИАТИВНОСТЬ) подтверждена.
- Стабильная форма = **эйгенформа** (von Foerster): неподвижная точка собственной динамики, результат — не подтерм реагентов.

## v1.1 — отбор форм (эксперимент поколений)

Форма 𝔉 как единица отбора: минимальный критерий \|F\|≥2 (сеянец жив), отбор по
(строгость, размер); контроль — случайный из живых; наследование — копия формы
с шумом. Якоря практики: минимальный критерий (Soros et al., ALIFE 2016),
POET (Lehman–Stanley 2019), Tierra (Ray 1992).

- **ФОРМА — АТТРАКТОР**: наследуемая форма удерживает мир — 0 смертей породы
  за 336 сеянцев в двух мирах (SKI 12 поколений, CHEM 30 поколений).
- **ПОДЪЁМА НЕТ**: отбор размера не растит \|F\| (SKI 4.5 против контроля 4.0;
  CHEM 18.5 против 20.0) — наследование даёт ИНВАРИАНТНОСТЬ, приток+шум — ВАРИАТИВНОСТЬ.
- **СТРОГИЕ ФОРМЫ 0/96** (SKI): эйгенформы не находятся локальным отбором наследуемых форм.

Байты: [GENERATIONS_RESULTS.md](GENERATIONS_RESULTS.md); открытые пункты — §9 MODEL.md.

## Сердцебиение (ФСМ-автомат)

Каждые 6 часов GitHub Actions будит `factum.py` — явный автомат:

    IDLE -> RECON -> IGNITE -> MEASURE -> RECORD -> IDLE

Один удар кладёт в [JOURNAL.md](JOURNAL.md) факты трёх миров: SKI, BCI, CHEM.
Журнал — **соты**: append-only, каждая строка данных несёт sha256 предыдущей строки
(подмену видно), первая несёт `GENESIS`. Целость: `python3 factum.py --verify`.

| мир | что меряем | FORM значит |
|---|---|---|
| SKI | gfp-организация + строгий критерий | есть эйгенформа (редко — так и задумано) |
| BCI | то же, линейный движок | есть эйгенформа (в BCI невозможна — ⋆ тотален) |
| CHEM | RAF-подобное самопроизводство | \|F\|≥2 — живой контур |

## Кардиограмма (ПУЛЬС) — кто следит за сердцем?

Сердце без кардиограммы умирает молча: крон может перестать биться, и никто не заметит
(правило 26: «активный крон, молчащий сверх порога, — тихая смерть»). Поэтому у сердца
есть собственная ЭКГ — `pulse.py`:

- **статусы честные**: `LIVE` (удар свежее 12 ч) / `STALE` (тишина = пропущено ≥2 удара) /
  `SOURCE_UNAVAILABLE` (журнал нечитаем). Красное — честно красное (правило 6).
- **свидетель**: `pulse.py --monitor` пишет в `PULSE_LOG.md` (соты: append-only,
  prev = sha256 предыдущей сырой строки, якорь sha256('PULSE')) строку ТОЛЬКО при смене
  статуса — история болезней сердца без шума.
- **дефибрилляция**: тишина сверх 12.5 ч → воркфлоу `pulse-monitor` сам запускает
  `factum-heartbeat` (правило 26: компенсация ручным диспатчем).
- **бейдж, который не может соврать**: `pulse.svg` рендерится из committed `pulse.json`,
  обновляется после каждого удара и каждого замера ЭКГ.

## Запуск

    python3 run_tests.py                  # 15 тестов модели
    python3 -m pytest -q                  # все тесты (модель + автомат + поколения)
    python3 factum.py --heartbeat         # один удар сердца (SKI + BCI + CHEM)
    python3 factum.py --verify            # целость хеш-цепочки сот

## Словарь улья

- **ФАКТУМ** (лат. factum — «сделанное»): Вико, *verum ipsum factum* — «истинно есть сделанное»; у улья это Закон #2 (факт = байты).
- **Эйгенформа**: стабильная форма = неподвижная точка собственной динамики (von Foerster, второго порядка кибернетика).
- **Соты**: append-only журнал; каждая ячейка — факт; подмену видно по хеш-цепочке.
- **Апейрон**: приток случайных термов — неисчерпаемый резервуар, из которого отбор берёт сырьё.
